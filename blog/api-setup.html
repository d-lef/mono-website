How to set up API AI models in mono

By Daniil Lefanov

mono runs AI locally by default — transcription and summaries happen on your own computer, and nothing is uploaded. That's the best option for privacy, and it's free. But local AI needs a reasonably capable machine. If mono told you your computer may struggle, or you just want faster results, you can connect a cloud API provider instead.

The short version

  • 1. Get an API key from Google Gemini, OpenAI, or Anthropic
  • 2. In mono, open Settings → AI
  • 3. Click Add AI Profile, pick your provider and model
  • 4. Paste your API key and click Save

Local vs. API: which should you use?

You don't have to choose permanently — you can switch any time in Settings. Here's the trade-off:

Local AI (default) API provider (cloud)
Free — no usage costs Pay-per-use to the provider
Fully private — audio never leaves your computer Audio/text is sent to the provider for processing
Needs a capable CPU/GPU; can be slow on older machines Fast on any machine — the work happens in the cloud
Works fully offline Requires an internet connection

An API provider makes the most sense when your computer can't run local models smoothly, or when you want the fastest possible transcription and summaries and don't mind sending data to the provider.

Step 1 — Get an API key

mono supports three cloud providers. Pick one and create an API key:

  • Google Gemini — get a key from Google AI Studio. Has a generous free tier, a good place to start.
  • OpenAI — get a key from platform.openai.com.
  • Anthropic Claude — get a key from console.anthropic.com.

Each provider asks you to create an account and add billing details (except Gemini's free tier). Your API key is a secret — treat it like a password. mono stores it on your computer and only sends it to the provider you chose.

Step 2 — Add the profile in mono

  1. Open mono and go to Settings → AI.
  2. Click Add AI Profile.
  3. Choose your Provider (Google Gemini, OpenAI, or Anthropic).
  4. Pick a Model. The default is a good choice — for example Gemini 2.5 Flash, GPT-4.1 Mini, or Claude Haiku for fast, low-cost results.
  5. Paste your API key and click Save.

mono tests the connection when you save. A green "ready" status means it's working. If you see an error like "Invalid API key" or "Quota exceeded", double-check the key and your provider's billing settings, then click Reconnect.

Tip: Start with a fast, inexpensive model (Gemini 2.5 Flash, GPT-4.1 Mini, or Claude Haiku). These are plenty for transcription and meeting summaries, and cost a fraction of the larger models.

That's it

New recordings will now be transcribed and summarised through your chosen provider. You can switch back to local AI, or between providers, any time under Settings → AI — your local models stay installed and ready.
